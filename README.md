# JORF_scans

Complete scans of the *Journal officiel de la République française* issues that publish the successive texts of loi n° 48-1484 du 25 septembre 1948 (Cour de discipline budgétaire et financière) and of the acts that amended it.

These are the original PDF files as published by Légifrance (DILA), kept unmodified so that excerpts and transcriptions in other repositories can cite a stable file by sha256. Pre-2004 issues are not available as text through the Légifrance API; only the scanned pages exist.

`MANIFEST.csv` lists, for each file: JO date and number, number of PDF pages, size, sha256, the Légifrance page of the act of interest and its number. The files carry no text layer.

Source and reuse conditions: Légifrance, https://www.legifrance.gouv.fr (DILA).

Consumer: https://github.com/GrasClement/cdbf, which versions only the relevant pages (excerpts cut losslessly from these files) and their transcriptions.
